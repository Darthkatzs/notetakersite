# Notatakersite

Legal documents for the Quiki app in HTML format.

## Files

- `terms-of-service.html` - Terms of Service for Quiki app
- `privacy-policy.html` - Privacy Policy for Quiki app

## Usage

These HTML files are self-contained with embedded CSS styling and can be:
- Opened directly in any web browser
- Deployed to any web server
- Integrated into existing websites
- Used as standalone legal document pages

## Features

- Responsive design that works on desktop, tablet, and mobile
- Professional styling with gradient headers
- Clean typography and organized content sections
- No external dependencies required

## About Quiki

Quiki is a smart AI note-taking app that provides:
- Audio recording and AI-powered transcription
- AI-powered text summarization
- Local note storage and management
- Cross-platform support (iOS, Android, Web)
